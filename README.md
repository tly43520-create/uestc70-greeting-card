# 芯艺 · 电子科技大学70周年贺卡

一张可以"抽出"的网页贺卡，按实体贺卡还原：橙色珠光封套、波浪开口与花形镂空、弹力绳蝴蝶结、金色银杏挂饰，以及印着电路与人像版画的内卡。

- 向上拖动封套里的内卡（或轻点），内卡抽出后会"通电"发光
- 轻点卡片翻面，阅读逐字显现的祝福语
- 「填写信息（选填）」：填写姓名、学院、班级，祝福语会随之生成
- 「编辑祝福」「分享」：修改祝福语，并复制带内容的链接

## 使用

用浏览器直接打开 `index.html` 即可，无需安装任何东西。默认祝福语在 `index.html` 脚本开头的 `CONFIG` 中修改。
